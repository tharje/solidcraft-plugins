Install a plugin

  1. Click Download .zip on a plugin (or take the zip from its latest release on GitHub).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

On macOS, SolidCraft 0.41 and 0.42 crash when any plugin runs (SolidCraft issue #16698). That is a SolidCraft bug, not the plugins'.

✓ Runs in SolidCraft … on a card: every night the newest SolidCraft (on Linux) loads the plugin's latest release and runs each of its commands with their default values. ✓ Loads: SolidCraft loaded it, but its commands need something picked first, so they weren't run. Plugins run in SolidCraft's sandbox, but no test can promise a plugin is safe: install plugins you trust, and use Report a problem on a card if one misbehaves.

What are SolidCraft plugins?

SolidCraft is a free, open-source parametric 3D CAD app for Windows, macOS, Linux and the web. It runs plugins: small WebAssembly programs that add a command to the Plugins menu and build parts from a form, such as a Gridfinity bin, an openGrid board, a spur gear or a threaded hole. What a plugin makes is ordinary SolidCraft sketches and features, so you can edit the result like anything you drew yourself.

SolidCraft asks before it installs a plugin and shows what it may do. Plugins run in a sandbox with time and memory limits, and anything extra they need, such as file access, is listed in their manifest.

Add your plugin

The list updates itself every day from GitHub. To get your plugin on it:

  1. Put it in a public GitHub repository with its plugin.json manifest.
  2. Add the topic solidcraft-plugin to the repository (the ⚙ next to About).
  3. Publish a release with the plugin zip attached, so people get a Download .zip button.

The first picture in your README becomes the card's picture. Name, description and menu entries come from your manifest.
