Quality checks

Some plugins on this list have been tested by hand, one version at a time. A plugin that passes gets the green ✓ Quality checked badge. One that doesn't is listed too, with what failed, so you can judge for yourself, and its author can see what to fix.

What is tested

A plugin passes when all of these hold for the version checked:

  1. Installs and loads in the newest SolidCraft
  2. Every command runs, with its defaults and with real settings
  3. Makes whole, valid bodies that can be edited
  4. Asks for no more than it needs, and never for the network
  5. Open source licence, a README, and a release with its zip
  6. Takes issues, for questions and bugs

How

The plugin's release zip is installed in the newest SolidCraft. Every command is run with its default values, and then with settings someone would really use: other sizes, the choices in its dialog, the largest and smallest values it allows, and on parts it is meant to work on. Each run is timed, and the bodies it makes are measured: they must be closed solids. Runs go through SolidCraft's own solidcraft-cli plugin test and the desktop app.

A plugin's page shows the result: each point ticked off or not, and a table of the runs with their settings, times and results. A check is for one version: after a newer release the badge turns grey until that one is checked too.

Ask for a check

Anyone can ask, authors too: use the Request a quality check form.
