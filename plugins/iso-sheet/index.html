Isometric Manufacture Sheet v1.1.0

Projects every body of the open design to a true isometric, removes hidden lines with a depth buffer, and writes a dimensioned ANSI B manufacture sheet as SVG: title block, bill of materials, parameter table, notes and overall dimensions.

Install Isometric Manufacture Sheet

  1. Download the zip above (from release v1.1.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v1.1.0 (2026-11-15)

1.1.0 adds a native scale dropdown and hardens the form values.

  • Scale is now a real dropdown: Auto, 1:1, 1:2, 1:5, 1:10, 1:20, 1:50, 1:100 (default Auto).
  • Date is validated as YYYY-MM-DD; empty uses today (UTC).
  • Write SVG to accepts a file name or a folder ending in / or \; .svg is added when missing.
  • Bodies match case-insensitively; an unknown name reports the available bodies.
  • Auto scale considers up to 1:100; enlargements display as 2:1; an overflowing drawing returns scale_note.
  • The result now includes date and available_bodies.

Still host-limited in SolidCraft 0.42.0: a dynamic body list, calendar picker and folder Browse need plugin-form support (tangency-labs/solidcraft#16274). The manifest marks format: date and format: path for forward compatibility.

Install: Preferences > Plugins > Install plugin... and pick iso-sheet.zip. Restart SolidCraft after a manual folder install.

Built with cargo-component against craft:plugin@0.1.0, target wasm32-unknown-unknown (no WASI imports).
