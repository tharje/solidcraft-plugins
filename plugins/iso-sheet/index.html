Isometric Manufacture Sheet v1.1.0

Projects every body of the open design to a true isometric, removes hidden lines with a depth buffer, and writes a dimensioned ANSI B manufacture sheet as SVG: title block, bill of materials, parameter table, notes and overall dimensions.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Isometric Sheet

Install Isometric Manufacture Sheet

  1. Download the zip above (from release v1.1.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub.
