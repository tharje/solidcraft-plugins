Gear Kit v1.0.0

Gears and timing belt pulleys for SolidCraft: spur, helical, herringbone, ring gear, rack, bevel and worm drives, and GT2, HTD, T, MXL and XL pulleys

Download .zip Source on GitHub

What it adds to SolidCraft

  • Spur / Helical Gears
  • Bevel Gears
  • Worm Gears
  • Timing Pulleys
  • Edit Gears

Install Gear Kit

  1. Download the zip above (from release v1.0.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v1.0.0 (2026-11-26)

First release.

  • Spur, helical and herringbone gears with a mating gear, ring gear or rack
  • Straight bevel gears
  • Worm drives
  • Timing pulleys for GT2, HTD, T, MXL and XL belts
  • Edit Gears: change gears and pulleys after they are built, in place

Requires SolidCraft 0.50.0 or later. Install: Plugins › Install plugin… in SolidCraft, then pick gear-kit-1.0.0.zip.
