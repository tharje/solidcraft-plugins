AprilCube v0.4.0

Generate printable cuboids and voxel targets with AprilTag or ArUco markers, edge chamfers, inlay recess and detector JSON.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Generate targets
  • Preview settings
  • Show tracking JSON

Install AprilCube

  1. Download the zip above (from release v0.4.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.4.0 (2026-11-14)

Generate editable two-color AprilTag and ArUco targets in SolidCraft desktop.

  • Build cuboids or voxel shapes, with distinct marker IDs across each batch.
  • Preview the marker layout and optionally engrave a label on each target.
  • Export tracking JSON and per-target 3MF files with the included Python companion.

Download the ZIP and choose Plugins → Install plugin… in SolidCraft desktop 0.41.0 or later. Use the accompanying SHA-256 file to verify the download.
