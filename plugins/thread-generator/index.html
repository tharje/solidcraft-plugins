Thread Generator v2.0.6

Quality check: could not be checked (v1.8.0)

Cut a 3D-printable thread into a shaft or hole. Select its round face in the design, then Run. Hover a field for what it does. The thread is an editable feature in the timeline; one Ctrl+Z takes the whole run back.

The plugin works in SolidCraft on every system. Its separate Thread Generator window (bolts, nuts, repaired 3MF) is Windows only.

Install Thread Generator

  1. Download the zip above (from release v1.8.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

What's new in v1.8.0 (2026-10-25)

Thread Generator for SolidCraft: 3D-printable threads with clearance, cut into the face you select in SolidCraft.

New in 1.8.0

  • One Size field. The separate Diameter and Pitch fields are gone, so the size you see is the size that's cut. Pick from the list or type your own, like M9x1.5.
  • 1 mm pitch on every size from M4 to M50 (M8x1, M10x1, …), next to 2, 2.5, 3.5 and 5 mm.
  • When you use a new face, the pitch you picked is kept and the diameter follows the face.
  • New defaults: M8x1, tolerance O.15, height 85%.

Install

  • Download thread-generator-1.8.0.zip below.
  • In SolidCraft open Preferences → Plugins → Show in folder and unzip it there, so you get plugins\thread-generator\plugin.json. Updating? Close Thread Generator first and replace the old folder.
  • Start ThreadGenerator.exe from that folder. Windows may say "Windows protected your PC" because the program isn't code-signed: click *More info → Run anyway*.

Needs Windows 10/11 and SolidCraft 0.22 or later for threading a face. No Python needed.

What it does

  • Thread a face in SolidCraft: select a shaft or the inside of a hole, pick a size, tolerance and height, and SolidCraft cuts a modeled thread into it.
  • 3D-printed metric sizes after CustomThreads: 1, 2 (experimental), 2.5, 3.5 and 5 mm pitches, plus ISO metric, fine and UNC.
  • Tolerance classes O.0, O.1, O.15, O.2, O.4, O.8 and height 70–100%: lower teeth with flat tops that still fit a matching nut.
  • A to-scale drawing of bolt and nut that explains each setting.
  • Export repaired 3MF: exports the selected body and runs Windows' own model repair on it, then opens it in your slicer.
