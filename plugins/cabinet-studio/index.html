Cabinet Studio v0.12.0

Cabinets, benchtops and cut lists in SolidCraft, from Cabinet Studio. Early test build.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Job setup
  • Cabinets panel
  • Rebuild all
  • Select cabinet
  • Open in its dialog
  • Open a Cabinet Studio job
  • Add cabinet
  • Edit cabinet
  • Boards
  • Bench top and panels
  • Cut list

Install Cabinet Studio

  1. Download the zip above (from release v0.12.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.12.0 (2026-11-28)

Cut List now adds a paginated whole-job cut list grouped by board and thickness. Choose Part drawings for an A3 sheet per part with an isolated model view, cut and finished sizes, quantity and edging. Everything generates both drawings. Cutting layouts in the SolidCraft drawing still use placement tables.
