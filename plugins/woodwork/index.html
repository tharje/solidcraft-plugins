Install Woodwork

  1. Download the zip above (from release v0.2.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.2.0 (2026-11-20)

Needs SolidCraft 0.45.

New

  • Cut list as a PDF, with a Format choice: PDF, CSV, Labels or DXF.
  • Edge banding and grain: banded edges per board, metres of banding to buy, grain direction, finished or cut sizes.
  • Cutting diagrams: sheets laid out with saw kerf, edge trim and grain, drawn in the PDF; sheets to buy counted from the layouts.
  • Part labels: a 3 x 8 sticker sheet, one label per board, with size, grain arrow and banded edges.
  • DXF for CNC: one file per sheet, holes on layers.
  • Inset fronts: doors and drawers inside the opening, with an adjustable reveal.
  • Sink base: a cabinet kind with an open top and rails.
  • Shop drawings: an A3 sheet per cabinet with front, side and 3D views, dimensions and a board list.
  • Tooltips: every dialog field explains itself on hover.

Changed

  • SolidCraft 0.45: the view frames the new cabinet after OK, and every function is a tool for the AI assistant.

Fixed

  • A board drawn at an angle in its own sketch is listed at its real size (#39).
  • The reveal can't be set below 0.5 mm.
  • An empty design gives an error instead of an empty cut list.
