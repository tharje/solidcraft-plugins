Install Woodwork

  1. Download the zip above (from release v0.5.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

It is on the SolidCraft Workshop too: its Open in SolidCraft button installs it, after SolidCraft shows what it asks for.

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.5.0 (2026-11-26)

Needs SolidCraft 0.49 or later (tested on 0.49.0).

One Cabinet dialog for new and picked cabinets

Cabinet has a Mode: Auto (see below), New cabinet or Edit picked. Edit picked works on one cabinet: the dialog starts at that cabinet's own values (sizes from Parameters) and shows only the fields it takes, and nothing is built when nothing changed. The separate Edit cabinet function is gone. What is design-wide, such as joinery and the finger-joint options, is in Woodwork settings.

Auto mode: new or edit from what you pick

Cabinet's Mode starts on Auto, which picks New or Edit from what is selected. Pick a door, drawer front, shelf, divider or drawer part, and Cabinet edits that cabinet. Pick a side, top, bottom or back and it makes a new cabinet next to that one; pick nothing for a new one on its own. The Mode hint says which it will do.

| Door picked: edits this cabinet | Side picked: a new cabinet next to it | |---|---| | | |

A new settings system

Woodwork settings now hold the choices that are the same for the whole design: joinery, hardware, plinth, fronts, the cut list and more. "Show settings for" picks one section (General, Doors and fronts, Drawers, Plinth / toe kick and wall mount, Joinery, Cut list and worktop, Display, or All); Units is set in General. The fields start at what is stored, and Settings only stores.

| Show settings for: the sections | The Joinery section | |---|---|
