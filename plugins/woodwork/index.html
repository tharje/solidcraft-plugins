Install Woodwork

  1. Download the zip above (from release v0.3.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.3.0 (2026-11-22)

Needs SolidCraft 0.46.

Drawers together with doors

A cabinet can now have drawers above or below its doors. On a cabinet with only drawers, set the top drawer's height and the ones below share the rest equally: a shallow top drawer over deeper ones.

| Before (0.2.0): doors or drawers | Now: a drawer over two doors | |---|---| | | |

Inset doors on corner cabinets

Corner cabinets take the same Fronts choice as box cabinets. Inset doors sit inside the carcass instead of over its edges.

| Before (0.2.0): overlay only | Now: inset | |---|---| | | |

Split L-shaped boards on corner cabinets

The L-shaped top, bottom and shelves can be cut as two dowelled rectangles (Boards: split). They fit on a sheet better and need no L-shaped cut.

| Before (0.2.0): one L-shaped piece | Now: two pieces (see the seam in the top) | |---|---| | | |

Plinth types

Besides the plain board (now with a set-back you can change), a plinth can be notched sides, legs or casters. Works on box and corner cabinets.

| Before (0.2.0): board only | Now: board, notched sides, legs, casters | |---|---|
