Lattice Generator v0.5.2

Gyroid/TPMS, strut and honeycomb lattices that fill the selected body as watertight meshes, with variable density by control points. SolidCraft 0.42+.

No release yet Source on GitHub

What it adds to SolidCraft

  • Gyroid
  • Gyroid VD
  • Struts
  • Struts VD
  • Honeycomb

Install Lattice Generator

  1. Build or download the plugin as described in its README on GitHub.
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub.
