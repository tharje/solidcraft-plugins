Install Box Importer

  1. Build or download the plugin as described in its README on GitHub.
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.49.0 (2026-11-26)

SolidCraft is open-source parametric 3D CAD in Rust: sketch, constrain, extrude, and change a parameter to watch the timeline rebuild. Documentation · try it in the browser · contributing · issues. AI agents can model with it over MCP: solidcraft-cli mcp (how).

What's new in SolidCraft 0.49.0 is listed below, and the roadmap detail lists the known limitations. Designs from every earlier version open in this one.

New app ID. The app ID is now io.tangencylabs.solidcraft (it was ai.storyteller.solidcraft): flatpak update offers to replace the old app, the .deb, .rpm and AppImage remove the old menu entry, and settings stay. On macOS the bundle ID changed too, so macOS asks once more for the permissions it had granted.

Old names. The zip container is the default save format. Want plain JSON? Use File ▸ Save As JSON… or --save design.json. Designs saved by earlier versions, including .solvecraft files, still open; the solvecraft-cli command, SOLVECRAFT_* variables and the .solvecraft file association are gone. Details: compatibility notes.

Documentation, the browser app and the Flatpak feed use the SolidCraft project Pages URLs.

Which file?

  • Windows: SolidCraft-0.49.0-windows-x64.exe runs as is. Or install the .msi, or unzip the -portable.zip (x64, x86 and arm64). IT admins: solidcraft-0.49.0-windows-policy-templates.zip
