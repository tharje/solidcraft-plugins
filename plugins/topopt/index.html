Install TopOpt

  1. Download the zip above (from release v0.12.2).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

It is on the SolidCraft Workshop too: its Open in SolidCraft button installs it, after SolidCraft shows what it asks for.

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.12.2 (2026-11-28)

Topology optimization for SolidCraft: pick a body, its supports and loads, and get a light, stiff part as a mesh or a solid.

New in 0.12.2

  • Clearer panel and dialogs. Every tab starts with a short note on what it is for. Each setting says its unit and what more or less does, with the default where it helps: "Keep, % of the body (less = lighter, weaker)", "Element budget (more = finer, slower)" and so on. The dialogs explain how to choose Keep, the element budget, the thinnest member and load cases. On the Run tab, Compliance says "lower = stiffer", and the rows read Elements and Through-holes.
  • One cover image with the FPV frame study's numbers. Renders that showed mesh artefacts are gone from the documentation.

Assets

  • topopt-0.12.2.zip: the plugin. Install it from Preferences › Plugins (or from the SolidCraft Workshop), then restart SolidCraft.
  • topopt-solvers-0.12.2-windows-x64.zip: TopOpt Solver (all CPU cores) and TopOpt CUDA Solver (NVIDIA GPU), optional. Run one on the folder granted to the plugin as results; Optimize then hands the run to it.

Also in 0.12

  • Every support joined to the part. Left to itself, the optimizer leads the load into the nearest supports and may leave a far bolt hole without material. Such a support is now made to hold the load alone in a helper load case and the study runs again, so every mounting point belongs to the part ("Join every support to the part", Settings, on by default).
  • Solids more often: triangles turned over inside the mesh surface, which SolidCraft could not sew, are mended.
  • Choosing the settings: what each study and mesh setting costs and gives, measured on a bracket with seven bolt holes.
