Install SolidInserts

  1. Download the zip above (from release v1.3.1).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

What's new in v1.3.1 (2026-11-24)

Captive Nut Pockets

SolidInserts now creates internal pockets for DIN 934 hex nuts that you insert during a print pause. Insert Seats remains available for heat-set inserts. The same ZIP works without patches on official SolidCraft Desktop 0.46.2 and 0.48.1. Compatibility with 0.48.1 was verified on Linux.

  • Select the hole rims and the face that rests on the print bed. Automatic sizing picks the nearest nominal nut size for each hole within ±0.25 mm. A Ø3 mm hole selects M3. Use manual sizing for ties or diameters outside that range.
  • Pause heights (mm) estimates where to pause with fixed layers, including a different first-layer height. For adaptive layers, set Layer height to 0 to see the geometric height at which each pocket closes.
  • Send to Slicer reuses the print face saved when you apply the pockets. Add the pauses in the slicer after checking its layer preview.

Captive Nut Pockets crea tasche interne per dadi esagonali DIN 934 da inserire durante una pausa di stampa. Insert Seats resta disponibile per gli inserti a caldo. Lo stesso ZIP funziona senza patch su SolidCraft Desktop 0.46.2 e 0.48.1 ufficiali. La compatibilità con la 0.48.1 è stata verificata su Linux.

  • La misura automatica sceglie per ciascun foro il diametro nominale più vicino entro ±0,25 mm. Un foro Ø3 mm seleziona M3. Scegli la misura manualmente se due diametri sono equidistanti o se il foro è fuori soglia.
  • Pause heights (mm) stima le quote di pausa per layer fissi, anche con un primo layer di altezza diversa. Per i layer adattivi, imposta Layer height a 0 per vedere la quota geometrica di chiusura di ogni tasca.
