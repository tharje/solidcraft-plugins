Job List v0.1.0

Keeps a list of machining jobs in the design and shows it in a docked panel.

An example from SolidCraft's own plugin guide, with its source code, for people making plugins. There is no zip: build it as the guide describes.

Plugin guide Source on GitHub

What it adds to SolidCraft

  • add
  • clear

Install Job List

  1. Build it as SolidCraft's plugin guide describes.
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.
