Generative Design Engine v0.4.2

Engineering material library (sourced cards), material report, a 2D stress check of flat parts with safety factor, and a plate optimiser (sketch + extrude). Third-party plugin, not affiliated with SolidCraft.

Install Generative Design Engine

  1. Download the zip above (from release v0.4.1).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.4.1 (2026-11-19)

Third-party plugin, not affiliated with SolidCraft or Tangency Labs; made independently, it only builds on their software. Tested with SolidCraft 0.44.1.

Changed in 0.4.1

  • Aluminium 6061-T6 and 7075-T6 now carry guaranteed specification minimums instead of ASM typical values: 6061-T6 yield 240 / tensile 260 MPa (extrusion and bar minimum; sheet and plate guarantee 240 / 290), 7075-T6 yield 460 / tensile 540 MPa (plate 6.3-12.5 mm, unclad). Sources: ASTM B209M-14 table 3, Aluminum Association table 11.1, EN 485-2 / EN 755-2. The shear strengths were removed (no specification guarantees one).
  • The stress check is therefore stricter for aluminium: allowable stress at safety factor 2 is 120 MPa (6061) and 230 MPa (7075). A design that passed with 0.4.0 may now report a lower safety factor.
  • The README and the plugin description state that this is a third-party project.

Everything else is as in 0.4.0: optimise-plate, apply-material, material-report, materials, stress-check, solver-benchmark, and the command-line tools stress3d, stress3d_printed, beam_opt.

Limits

  • A design aid, not a certified analysis. The plate optimiser checks stiffness only; run stress-check on its result.
  • Thicker plate, clad sheet and other product forms have other minimums; check your supplier's certificate. The inch-pound ASTM text is paywalled, so the ksi figures are converted.
  • Designs that already hold an older aluminium card (same name, other values) make apply-material refuse until the old material is renamed.

Install: Preferences > Plugins > Install plugin... and pick gen-design-engine-0.4.1.zip, or plugin.install {"path": ".../gen-design-engine-0.4.1.zip", "replace": true}. Check the download with gen-design-engine-0.4.1.zip.sha256 (sha256sum -c).
