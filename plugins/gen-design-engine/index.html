Generative Design Engine v0.14.0

Engineering material library (sourced cards), material report, a 2D stress check of flat parts with safety factor, a plate optimiser and a round-bar bracket designer (truss). Third-party plugin, not affiliated with SolidCraft.

Install Generative Design Engine

  1. Download the zip above (from release v0.14.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.14.0 (2026-11-26)

Third-party plugin, not affiliated with SolidCraft; it only builds on their software.

Stress check

  • Clamped edges read the same at every grid (#147, PR #149). Where a flat support meets a free edge the stress is singular, so the peak there used to grow with every finer grid (100 x 10 x 5 mm aluminium cantilever, 100 N: 118.5 / 123.4 / 125.9 / 139.9 MPa at 120 / 200 / 240 / 400 cells; beam theory 120). The verdict's peak is now extrapolated to those corners from the peaks beyond r and 2r (hot-spot style): 118.4 / 119.0 / 119.5 / 119.2 MPa. The singular value stays in the reply (singular_peak_mpa); peak_read says how the peak was read. Supports on holes keep the plain surface peak. Note: verdicts at clamped corners can change; that cantilever at 200 cells now passes SF 2.02 (was 1.94).
  • verify (#144): solves again at half the resolution; converged only when displacement and peak settle (2 % / 5 %), otherwise unverifiable and no pass/fail verdict.

Every refusal says what to fix (#141, #142)

  • One shape: <what was wrong>. Fix: <what to change>. [<code>], e.g. volume_share is 0.95, outside 0.1 to 0.9. Fix: set volume_share from 0.1 to 0.9. [out_of_range]. Eleven codes, listed in the README.
  • The ranges and choices the plugin accepts are now exactly the ones the dialog offers (one generated table, every bound tested). Fixed on the way: stress-check forces are declared up to 1e9 N; bar-bracket and benchmark refusals name the field instead of "params"; bar-bracket honours a cancel before its long part.
