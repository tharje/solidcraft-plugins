Generative Design Engine v0.10.0

Engineering material library (sourced cards), material report, a 2D stress check of flat parts with safety factor, a plate optimiser and a round-bar bracket designer (truss). Third-party plugin, not affiliated with SolidCraft.

Install Generative Design Engine

  1. Download the zip above (from release v0.10.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.10.0 (2026-11-22)

Third-party plugin, not affiliated with SolidCraft or Tangency Labs; made independently, it only builds on their software. Tested with SolidCraft 0.45.0 (tests/cli-test.sh PASS, solidcraft-cli plugin check: no problems).

0.10.0 adds a custom setup for the plate optimiser and the fixes from a second review. Main theme of the review: no check says "passes" for a part it did not really check.

New

  • optimise-plate: custom setup (#87, #91). Load case custom with one setup text: held edges, point loads, solid areas and holes, in mm from the plate's lower-left corner. plate_refine takes setup= too.

Results that change

  • stress-check gives no verdict when it could not really check (#113, #114). "Not checked" (passes: false) when the solve did not converge, no stress was measured, or more than 5 % of the force points through the plate.
  • Round faces (#109, #112). A support or load on a fillet or on half of a split hole now takes only that face's arc, not the whole circle through solid material.
  • eso3d bar checks hold the wall over the check voxel (#112). With a coarse voxel=, half the plate used to be held rigid (stress too low). Default settings give the same result as before.

No more false passes (command-line tools)

  • stress3d: needs a converged solve and a measured peak.
  • eso3d: a starting block that already fails SF stops with an error. A bar or plate with nothing measured cannot pass. An unconverged round no longer ends the sizing.
  • beam_opt: a pad longer than the beam, a safety factor of 0 or less, or a strut length of 0 or less are refused. Each used to make every design pass.

Input checks

  • A malformed mesh entry is an error (it used to be skipped and shifted the geometry).
