Generative Design Engine v0.14.2

Engineering material library (sourced cards), material report, a 2D stress check of flat parts with safety factor, a plate optimiser and a round-bar bracket designer (truss). Third-party plugin, not affiliated with SolidCraft.

Download .zip Source on GitHub

  • optimise-plate
  • bar-bracket
  • solver-benchmark

Install Generative Design Engine

  1. Download the zip above (from release v0.14.2).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.14.2 (2026-11-27)

Third-party plugin, not affiliated with SolidCraft; it only builds on their software.

The plugin itself is unchanged from 0.14.1 (same behaviour, same 13 test cases). This release follows main:

  • The manual says how to test a changed version with tests/run-all.sh (#156, PR #158).
  • The README shows the 3D showcase renders of the MBB beam: a path-traced metallic render, four close-ups, and the von Mises stress painted on the 3D beam (#157, PR #158).

Tested on SolidCraft 0.50.0, headless (tests/run-all.sh: 8 of 8 stages, plugin test: 13 passed). Not tried in a window yet. Unsigned; check the zip against the .sha256.
