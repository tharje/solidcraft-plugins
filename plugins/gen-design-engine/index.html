Generative Design Engine v0.11.0

Engineering material library (sourced cards), material report, a 2D stress check of flat parts with safety factor, a plate optimiser and a round-bar bracket designer (truss). Third-party plugin, not affiliated with SolidCraft.

Install Generative Design Engine

  1. Download the zip above (from release v0.11.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.11.0 (2026-11-22)

Third-party plugin for SolidCraft; not affiliated with or endorsed by its makers. It only builds on their plugin interface.

Needs SolidCraft 0.45.0 or newer (plugin.json is now 18 KiB; older versions accept 16 KiB).

New (#120, #121):

  • optimise-plate: symmetry — none, left-right, top-bottom or both; the shape stays mirrored whatever the loads.
  • optimise-plate: strength estimate — peak and 99th-percentile stress for the given force, safety factor against yield, a safety_factor target (default 2) and the thickness needed when it falls short. A quick grid estimate: it reads sharp corners lower than stress-check, so run stress-check on the drawn body before relying on it.
  • Six materials other generative design tools ship: AISI 1018 cold drawn, CoCrMo (ASTM F3213), maraging 1.2709 aged (EOS MS1), PEEK 450G, PA6 and PA66 (conditioned). 32 in total.

Hardening:

  • Manifest limit check raised to SolidCraft's 64 KiB.
  • plate_refine refuses unknown or repeated keys; new symmetry= and sf=.
  • eso3d's SolidCraft sweep script builds again (fit points at least 4 bar radii apart; fixes "control net doubles back").

Tested with SolidCraft 0.45.0 (tests/cli-test.sh PASS: 32 materials created, assigned and kept after reopening). A design aid, not a certified analysis.
