Generative Design Engine v0.13.0

Engineering material library (sourced cards), material report, a 2D stress check of flat parts with safety factor, a plate optimiser and a round-bar bracket designer (truss). Third-party plugin, not affiliated with SolidCraft.

Install Generative Design Engine

  1. Download the zip above (from release v0.13.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.13.0 (2026-11-24)

Third-party plugin, not affiliated with SolidCraft; it only builds on their software.

Build direction and 45 degree overhang limit in optimise-plate (issue #130, PR #131)

  • New setting build_direction: none (default), up, down, left or right. The optimiser then keeps every cell supported by the cells below it (layer filter after Langelaar et al., 45 degrees, with an exact adjoint), so the design can be printed without supports.
  • The result reports the overhang outcome. It is not a hard guarantee: the default plate with up still reports 2 cells that need support.
  • New plugin test case optimise-plate-build-up and an end-to-end step in tests/cli-test.sh.

Tested on SolidCraft 0.48.1, headless (tests/cli-test.sh PASS, plugin test: 12 passed). Not tried in a window yet. Unsigned; check the zip against the .sha256.
