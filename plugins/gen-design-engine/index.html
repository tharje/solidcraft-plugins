Generative Design Engine v0.16.1

✓ Quality checked (v0.15.0) · 39/39

Engineering material library (sourced cards), material report, a 2D stress check of flat parts with safety factor, a plate optimiser and a round-bar bracket designer (truss). Third-party plugin, not affiliated with SolidCraft.

Install Generative Design Engine

  1. Download the zip above (from release v0.16.1).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.16.1 (2026-11-28)

Ten review fixes (#175-#184, PR #186). No new fields; tested on SolidCraft 0.51.2 (tests/run-all.sh: all 8 stages).

  • stress-check: verify needs a resolution of 20 or more (at 10 it compared the grid with itself and always read converged) (#175)
  • optimise-plate: the Force field's text says what it does (with goal Lightest it sets the shape; not used with load case Custom) (#176)
  • goal Lightest: no refusal for the unused volume_share (#177); the as-drawn check skips unconverged solves and no longer reads 0 when every solid cell is next to a point (#178)
  • the material share holds with a mirror and one-sided void or kept cells (0.424 for 0.40 before) (#179)
  • native tools: stress3d_printed mass from the library density (#180); beam_opt jobs= caps every thread (#181) and yield defaults to 240 MPa (#182); plate_refine checks --out before the run (#183)
  • tests/cli-test.sh always runs plugin test (#184)
