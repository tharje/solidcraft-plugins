Generative Design Engine v0.10.2

Engineering material library (sourced cards), material report, a 2D stress check of flat parts with safety factor, a plate optimiser and a round-bar bracket designer (truss). Third-party plugin, not affiliated with SolidCraft.

Install Generative Design Engine

  1. Download the zip above (from release v0.10.2).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.10.2 (2026-11-22)

Third-party plugin, not affiliated with SolidCraft or Tangency Labs; made independently, it only builds on their software. Tested with SolidCraft 0.45.0 (tests/cli-test.sh PASS, solidcraft-cli plugin check: no problems).

0.10.2 fixes a bug found by trying the custom plate setup in SolidCraft (#118, #119).

  • Corner rounding no longer fills the custom setup's holes. The rounding only adds material, so it closed every hole narrower than the fillet, including the holes asked for in Setup. With the manual's example, a 1 mm fillet closed the Ø3.4 mm screw hole. Setup holes now always stay open; other small holes still close, as before.
  • Height note for custom plates. When the plate height snaps to whole grid cells (for example 51 → 51.75 mm), the reply now says so even under 3 %, because setup points on the top edge then sit inside the plate.

Install: download the zip, check it with sha256sum -c gen-design-engine-0.10.2.zip.sha256, then plugin.install with the zip's path.
