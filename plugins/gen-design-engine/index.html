Generative Design Engine v0.6.0

Engineering material library (sourced cards), material report, a 2D stress check of flat parts with safety factor, and a plate optimiser (sketch + extrude). Third-party plugin, not affiliated with SolidCraft.

Install Generative Design Engine

  1. Download the zip above (from release v0.6.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.6.0 (2026-11-19)

Third-party plugin, not affiliated with SolidCraft or Tangency Labs; made independently, it only builds on their software. Tested with SolidCraft 0.44.1.

Changed in 0.6.0

  • Corner rounding in optimise-plate: a new *Corner rounding* field (round_mm) puts a round fillet of that radius wherever members meet. It is a morphological closing on an exact distance transform, so it only adds material (a few per cent): no member gets thinner, and holes narrower than the fillet close. The outline follows the fillets between the grid cells.
  • Refine pass (plate_refine, a command-line tool in the source, built with --features gpu): the same optimisation outside the plugin's limits, up to 800 cells across, solved on the GPU, with the smallest member in mm (so finer grids stay printable) and rounding on by default. It writes a script that builds the body in SolidCraft (solidcraft-cli run). The plugin's reply points to it.
  • GPU load limit (gpu_max, default 80 %): the tool pauses after every solver step, and where the kernel reports the GPU's busy share (amdgpu) it lengthens the pauses while the whole GPU, desktop included, is over the limit. Measured on an RX 5700 XT: 200 x 100 mm at 480 x 240 cells in about 19 s, GPU at most 80 % busy.

Measured on a 200 x 100 x 10 mm PETG cantilever: the plugin result (160 x 80 cells) weighs 102 g with safety factor 5.9; the refine pass (480 x 240 cells, 3 mm smallest member, 4 mm fillets) 104 g with safety factor 6.1.

Everything else is as in 0.5.1: optimise-plate, apply-material, material-report, materials, stress-check, solver-benchmark, and the command-line tools stress3d, stress3d_printed, beam_opt (multigrid 3D solver).
