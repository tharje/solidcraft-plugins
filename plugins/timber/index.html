What's new in 0.1.1 (2026-11-19)

Timber plugin for SolidCraft 0.43 or later.

Install: download timber-0.1.1.zip, then in SolidCraft open Preferences › Plugins › Install plugin… and pick it (tick Replace if an earlier Timber is installed).

In this release

  • Standard timber sections (4x2, 3x2, 2x2, CLS, 6x2/8x2 joists, 3x3/4x4 posts, battens) or a custom size, at any length
  • Place at the origin, or parallel or at 90° to a selected timber: beside, on top, underneath, or across an end
  • Runs of several pieces at a centre-to-centre spacing
  • Inches checkbox; lengths can also be typed with their own unit: 2400 mm, 2.4 m, 8' 6", 1 1/2"
  • Length and section saved as design parameters

Files

  • timber-0.1.1.zip: the plugin, ready to install
  • timber-0.1.1-source.zip: the Rust source
