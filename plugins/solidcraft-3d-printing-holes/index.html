3D Printing Holes v0.1.0

Holes made for 3D printing. Teardrop: select sketch circles, then run it; each gets a small tip a few percent of the radius above it (it follows the radius), so the top of a horizontal hole does not sag.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Teardrop

Install 3D Printing Holes

  1. Download the zip above (from release v0.1.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub.
