3D Printing Holes v0.2.0

Holes made for 3D printing. Teardrop: select sketch circles, then run it; each gets a small tip a few percent of the diameter above it (it follows the diameter), so the top of a horizontal hole does not sag.

Install 3D Printing Holes

  1. Download the zip above (from release v0.2.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.2.0 (2026-11-16)

Changed

  • Tip size is now given in percent of the diameter (tip_extra_d, default 2.5 %). The default teardrop is unchanged (tip at 1.05·r); only the way it is specified changed. The tip dimension keeps the percentage visible in its expression, e.g. hole_d / 2 + hole_d * 2.5 / 100, so you can edit it for a single hole later.
  • Apply to all circles in sketch is now a checkbox (replaces the *Circles* dropdown).
  • Tip direction (formerly *Up*) has clearer choices: world +Z (print up) and sketch +X / -X / +Y / -Y.
  • Override: tip from centre (formerly *Tip height*) also accepts d for the diameter, e.g. d/2 + 0.3 mm or d*sqrt(2)/2 for a classic 45° teardrop.

Removed

  • *Flat top at* (flat_top).
  • The *Up angle* form field. A custom angle can still be passed from scripts, e.g. up: "300".

Compatibility

Scripts that use the old inputs keep working: tip_extra (percent of the radius) and scope ("selected" / "all in sketch") are still accepted, as are the short up values auto, +x, -x, +y, -y.
