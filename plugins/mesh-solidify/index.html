Mesh Solidify v0.2.0

Rebuild a broken mesh body (holes, open shells, overlaps) as one watertight, printable solid. Adds the result as a new body.

Install Mesh Solidify

  1. Download the zip above (from release v0.2.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

Highlights

  • Plugin: *Solidify Mesh…* rebuilds the selected mesh body as a new watertight body in one undo step. The dialog defaults to 10% scale. *Inspect Mesh…* reports holes, loose parts and size.
  • CLI: same flags, --json and exit codes as 0.1; about 2× faster with a quarter of the memory (978k-triangle compressor: 35 s instead of 76 s; 650k-triangle toolbox at 400M voxels: 34 s and 2 GB instead of 123 s and 7.8 GB). New --voxel auto and --threads; reads PLY.
  • Octree winding-number evaluation, marching tetrahedra, manifold-preserving decimation, void filling.

SolidCraft 0.41.0 limits

These are the host's limits, not the plugin's:

  • A plugin can read mesh bodies of at most 2,730 triangles, and send back about 30,000. For larger scans use the CLI and *Insert Mesh*.
  • macOS: the signed 0.41.0 build lacks the JIT entitlement Wasmtime needs, so running *any* plugin kills the process ("Code Signature Invalid"). Use a build without the hardened runtime until SolidCraft fixes it.
