Install Gears

  1. Download the zip above (from release v0.1.1).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

How it could pass

The time grows with the number of teeth, about 0.35 s a tooth here. Making Make gear a long job ("job": true, SolidCraft 0.48 and later: up to ten minutes, with progress and Cancel), or drawing one tooth and patterning it, would fix it. Reporting a pointed tooth as an invalid setting would make that message clearer.
