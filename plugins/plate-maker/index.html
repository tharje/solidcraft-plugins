Install Plate Maker

  1. Build or download the plugin as described in its README on GitHub.
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.45.0b-android (2026-11-20)

SolidCraft 0.45.0b for Android and Googlebook OS (SolidCraft 0.45.0, port release b).

Built from upstream SolidCraft v0.45.0 (e8ce12ef) with the Android port on top.

Install: on an Android 8.0+ phone or tablet, or a Googlebook with a Snapdragon (Arm) chip, download SolidCraft-0.45.0b-android-arm64.apk; on a Googlebook with an Intel chip, SolidCraft-0.45.0b-android-x86_64.apk. Open it, allowing installs from that source, or adb install -r it. Signed with a development key: uninstall a build from elsewhere first if Android refuses to update it.

Works: the full SolidCraft app (sketches, features, the timeline, the Render workspace) on Vulkan or GLES; mouse and keyboard as on the desktop (hover, selection, navigation buttons, wheel, right-click menu, shortcuts); touch (one finger orbits, tap selects, two fingers pan, pinch zooms, a finger drags a dialog's arrows); Back closes what is open; open, save, import and export through Android's file picker (STEP, STL, 3MF and OBJ tested); the on-screen keyboard for typing. Desktop windows (Samsung DeX, Googlebook OS) with the app's own bar below the window's title bar; an MCP server on the network for AI agents (Settings › MCP server). Designs are upstream's own format: they open in upstream SolidCraft of the same version, and plugins (Preferences › Plugins) install as upstream's do.
