Install Bearings

  1. Build or download the plugin as described in its README on GitHub.
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.2.0 (2026-11-15)

Screws and pocketed nuts now stay attached as designs change, and extrusion rails can follow sketch paths.

Screws

  • Screw and hole creates native rigid joints for clearance, counterbored, countersunk and tapped placements. Moving a source sketch point moves its screw; changing a counterbore depth moves the screw with the floor.
  • Tapped attachments work with layout sketches created before the solid, face-mounted sketches and placement from another active component.
  • Attachments survive save/reopen and work in saved designs without the plugin installed. Identical screw definitions remain reusable across runs.
  • The screw README compares the plugin with SolidCraft 0.42's built-in fasteners, including modeled threads, custom heads and drives, the combined hole workflow, and the built-in tool's preview and sizing advantages.

Nuts and extrusions

  • Nut pockets follow source sketch positions and orientation. Native joints keep pocketed nuts seated through moves and depth changes.
  • Nut pocket hexes retain their alignment through large sketch moves and share one editable across-flats dimension.
  • Sketch driven extrusions create independent rails from straight sketch lines. Rail length, position, orientation, end taps and cross-holes follow path edits; hole offsets can be measured from either end.
  • Fixed-length extrusion screw holes use editable reference sketches so their access and clearance cuts move together.
