What's new in v0.10.0 (2026-11-20)

Woodworking joints for SolidCraft, as a command plugin. This version takes its default proportions from French cabinetmaking practice, warns of joints that practice avoids, and adds four variants.

The defaults changed. A joint made with empty fields is no longer the same as with v0.9: longer blind tenons, wider haunches, steeper dovetails. Joints already in a design are not touched. To make them as before, fill in the fields (see below).

Install

You need the SolidCraft desktop application, version 0.42.0 or later. The icons show from version 0.44.0.

  • Download wood-joinery-en.zip (English) or wood-joinery-fr.zip (French) below. Do not take the "Source code" archives, and do not unzip the file.
  • In SolidCraft, open Preferences › Plugins › Install plugin… and pick the file.
  • The commands are in the Plugins group of the Model tab.

Install one package only. Both have the same plugin id. The README has the full steps.

New defaults

| Setting | v0.9 | v0.10 | As before | |---|---|---|---| | Blind tenon length | 2/3 of the stile | 3/4 of the stile, the mortise still 2 mm deeper | give length | | Haunch width | 1/5 of the rail | 1/4 of the rail | give haunch_width | | Dovetail slope | 1:8 | 1:6, about 80° (French practice: about 78°, 1:5) | slope 8 | | Two pegs | on one line, half way along the tenon | on a diagonal, at a third and two thirds of it | — | | Dowels | any board | refused in boards under 11 mm | — |

The sources are French cabinetmaking references: the FCBA manual on wood joints (proportions), a cabinetmaking course (dovetail slope, dowels, mortise cheeks), and vocational course sheets on pegging.
