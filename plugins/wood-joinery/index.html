Wood joinery v0.9.0

Woodworking joints between boards: mortise and tenon, grooves, half laps, dowels, box joints, loose tenons, housings, miters, tongue and groove, scarfs, dovetails, screws and biscuits.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Mortise and tenon
  • Loose tenon
  • Groove
  • Tongue and groove
  • Housing joint
  • Half lap
  • Miter joint
  • Scarf joint
  • Box joints
  • Dovetails
  • Dowels
  • Biscuits
  • Screws

Install Wood joinery

  1. Download the zip above (from release v0.9.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub.
