Install Wood joinery

  1. Download the zip above (from release v0.15.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.15.0 (2026-11-27)

Woodworking joints for SolidCraft, as a command plugin. In this version you pick the boards with a click, a docked *Joints* panel lists the joints of the design, and the French package speaks French. It is made for SolidCraft 0.51.

Install

You need the SolidCraft desktop application, version 0.51.0 or later. On 0.50 everything works but opening a joint's form from the Joints panel. On SolidCraft 0.46 to 0.49, install v0.13.0 instead.

  • Download wood-joinery-en.zip (English) or wood-joinery-fr.zip (French) below. Do not take the "Source code" archives, and do not unzip the file.
  • In SolidCraft, open Preferences › Plugins. If an older version is installed, click Remove on its card first.
  • Click Install plugin… and pick the file. The plugin asks for the same commands as 0.14.0, and for one more capability, ui, for the Joints panel.

Install one package only. Both have the same plugin id. Your designs keep their joints, and Edit a joint and Update joints read the joints made with older versions.

New

  • Pick the boards with a click. The board fields of the thirteen joints work like Extrude's *Profiles*: the first one is active when the form opens, a click on a board in the view or in the browser fills it, and the next field takes the next click. Each field shows the board's name and a cross to empty it. Boards selected before you open the form still fill it.
