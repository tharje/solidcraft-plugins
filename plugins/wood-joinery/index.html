Wood joinery v0.9.0

Woodworking joints between boards: mortise and tenon, grooves, half laps, dowels, box joints, loose tenons, housings, miters, tongue and groove, scarfs, dovetails, screws and biscuits.

Install Wood joinery

  1. Download the zip above (from release v0.9.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.9.0 (2026-11-17)

Woodworking joints for SolidCraft, as a command plugin. This version gives each command its own icon. The joints themselves are the same as in v0.8.2.

Install

You need the SolidCraft desktop application, version 0.42.0 or later. The icons show from version 0.44.0.

  • Download wood-joinery-en.zip (English) or wood-joinery-fr.zip (French) below. Do not take the "Source code" archives, and do not unzip the file.
  • In SolidCraft, open Preferences › Plugins › Install plugin… and pick the file.
  • The commands are in the Plugins group of the Model tab.

Install one package only. Both have the same plugin id. The README has the full steps.

New since v0.8.2

  • An icon for each command: SolidCraft 0.44 draws it on the ribbon button, in the menus and in the dialog's header. Each icon shows the boards in grey and the part that makes the joint in blue, such as the tenon, the dowels or the screw.
  • The icons use only the colours of the SolidCraft icon palette, so they follow the light and dark themes.
  • SolidCraft 0.42 and 0.43 ignore the icons and show the generic plugin icon, as before.

Limits

  • The boards must lie along the X, Y and Z axes.
  • The joints are not parametric: they add ordinary features in one undo step.
  • The cuts at an angle add many features: six for a miter or a scarf, nine for each dovetail, eight for each wedge.
  • A board in a component that was turned or moved is not supported yet. The command then fails with a message and changes nothing.
  • A tenon does not adjust itself to a groove already cut.
  • Error messages are in English in both packages.
