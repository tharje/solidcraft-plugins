Install Wood joinery

  1. Download the zip above (from release v0.12.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.12.0 (2026-11-22)

Woodworking joints for SolidCraft, as a command plugin. This version makes joints follow a change of sizes, adds Festool Dominos, and shows each form field only when it applies.

Install

You need the SolidCraft desktop application, version 0.46.0 or later. On SolidCraft 0.42 to 0.45, install v0.10.1: older versions cannot draw these forms.

  • Download wood-joinery-en.zip (English) or wood-joinery-fr.zip (French) below. Do not take the "Source code" archives, and do not unzip the file.
  • In SolidCraft, open Preferences › Plugins. If an older version is installed, click Remove on its card first.
  • Click Install plugin… and pick the file. The plugin now asks for thirteen commands and the storage and forms capabilities; the README says what each is for.

Install one package only. Both have the same plugin id.

New

  • Update joints. A joint's cuts are boxes at fixed sizes. The plugin now keeps each joint in the design, in a timeline folder of its own. After a change of parameters, *Update joints* makes every joint again on the boards as they are, with its settings. When nothing changed since the last update, it does nothing; a box makes them all again anyway.
  • Large designs update in runs. SolidCraft allows a plugin 256 commands in one run. A design with more joints updates what fits, and the window opens again until all are done. A bedside table with 53 joints takes three runs.
  • Edit a joint. Opens a joint's own form, filled with its settings. Change what you need and apply: the joint is made again in its place.
