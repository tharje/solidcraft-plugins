Wood joinery v0.6.0

Woodworking joints between boards: mortise and tenon, grooves, half laps, dowels, box joints, loose tenons, housings, miters, tongue and groove, scarfs, dovetails and screws.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Mortise and tenon
  • Groove
  • Half lap
  • Dowels
  • Box joint
  • Loose tenon
  • Housing
  • Miter
  • Tongue and groove
  • Scarf joint
  • Dovetails
  • Screws

Install Wood joinery

  1. Download the zip above (from release v0.6.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub.
