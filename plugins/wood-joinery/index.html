Install Wood joinery

  1. Download the zip above (from release v0.9.1).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.9.1 (2026-11-19)

Woodworking joints for SolidCraft, as a command plugin. This version lets a command run for up to 30 seconds and sets a limit on the number of pieces one call makes. The joints themselves are the same as in v0.9.0.

Install

You need the SolidCraft desktop application, version 0.42.0 or later. The icons show from version 0.44.0.

  • Download wood-joinery-en.zip (English) or wood-joinery-fr.zip (French) below. Do not take the "Source code" archives, and do not unzip the file.
  • In SolidCraft, open Preferences › Plugins › Install plugin… and pick the file.
  • The commands are in the Plugins group of the Model tab.

Install one package only. Both have the same plugin id. The README has the full steps.

New since v0.9.0

  • 30 seconds per call instead of 10. SolidCraft stops a plugin command after its time limit. With 10 seconds, 30 dowels or 20 biscuits on a long joint could fail on a slow computer, with a message that asked to contact the author.
  • A limit on the number of pieces, so that one call stays well inside SolidCraft's 30 seconds and 256 commands:

| Joint | At most | |---|---| | Dowels | 30 | | Biscuits | 30 | | Loose tenons | 40 | | Screws | 15 | | Dovetails | 20 | | Box joint divisions | 60 |

A larger count is refused at once, and nothing is cut. When the count is left empty, the number worked out from the length stops at the same limit: on a very long joint, the pieces are further apart.

Limits

  • The boards must lie along the X, Y and Z axes.
  • The joints are not parametric: they add ordinary features in one undo step.
  • The cuts at an angle add many features: six for a miter or a scarf, nine for each dovetail, eight for each wedge.
