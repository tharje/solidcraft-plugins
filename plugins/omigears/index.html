What's new in v0.50.2 (2026-11-27)

OmiGears 0.50.2 makes gears editable: Edit gear reopens a gear's form, filled in with the inputs it was made with, and changes the gear where it is in the timeline. The commands now sit behind one Gears button, and each gear gets the number of points per flank it needs.

Install

  • With OmiGears 0.50.1 installed, take the update SolidCraft offers on its card in Preferences › Plugins. Otherwise download omigears-0.50.2.zip below.
  • In SolidCraft (desktop): Preferences › Plugins › Install plugin… and pick the zip. It asks for no permissions.

Requires SolidCraft 0.50.0 or later. SolidCraft 0.49.1 offers this update to OmiGears 0.50.1 too, but refuses the package when it installs: update SolidCraft first, or keep OmiGears 0.50.1.

New

  • Edit gear. Pick a gear's body or one of its faces, and its form opens filled in with the inputs it was made with. Change them and Run:
  • Most changes are made in place: teeth, module, angles, width, bore, points. Each sketch and feature changes where it is in the timeline, keeping its id. Features you added after the gear (a hole, a fillet, a join) are rebuilt on the changed gear.
  • Changes that make other steps rebuild the gear where it was: crowning turned on or off, a pinion or mate added or left out, another number of worm starts, a bevel's or hypoid's bore. The reply lists any later feature that then fails, so you can pick its references again.
  • A set made by one run (a planetary set, a rack and its pinion, a cycloidal pair, a cycloidal drive) changes together.
  • The edit is one undo step, and names follow the new inputs ("Spur gear z24 m2").
