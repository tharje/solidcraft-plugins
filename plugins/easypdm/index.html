EasyPDM v0.9.0

Upload designs to an EasyPDM server and download them, through the EasyPDM companion program.

Needs an EasyPDM server and the EasyPDM companion program, which also makes the plugin zip for each computer.

  • Download

Install EasyPDM

  1. Download the zip above (from release v0.9.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.9.0 (2026-11-17)

In short: the first release of EasyPDM for SolidCraft from its own repository: the same plugin and companion as attached to EasyPDM 0.9.0, now released here. Upload, Download, Log in and Log out in SolidCraft's Plugins menu, assemblies of linked designs, transparent previews, signing in through the browser. Needs SolidCraft 0.43 or later and an EasyPDM 0.9 server.

Install: download the companion zip for your system below (win-x64 or linux-x64); it holds the companion program and the plugin, with nothing else to install. Then follow installing step by step on the wiki: log in, set up the plugin, install it in SolidCraft, start the companion with your login.

Changed

  • A repository of its own, moved out of EasyPDM (EasyPDM.SolidCraft/ became the top level and plugin/, EasyPDM.Companion/ became companion/) with its history, released on its own as the FreeCAD and SolidWorks integrations are.
