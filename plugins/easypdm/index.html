EasyPDM v0.9.1

Upload designs to an EasyPDM server and download them, through the EasyPDM companion program.

Needs an EasyPDM server and the EasyPDM companion program, which also makes the plugin zip for each computer.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Upload
  • Download
  • Log in
  • Log out

Install EasyPDM

  1. Download the zip above (from release v0.9.1).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.9.1 (2026-11-27)

In short: Log in, Log out and Download work again in newer SolidCraft versions, which refused them with "permission denied: read entry may not use the host import write-file".

Update: unpack the new companion zip over the old one, run easypdm-companion setup-solidcraft again and reinstall the plugin it writes (Preferences > Plugins), granting the same file command group and outbox folder.

Fixed

  • "permission denied: read entry may not use the host import write-file". Log in, Log out and Download were declared as read-only entries, yet each leaves its request for the companion in the outbox folder. SolidCraft now refuses file writes to read-only entries, whatever folders the plugin was granted, so they failed before doing anything. They are now declared as edit entries, like Upload; they still change nothing in the design. (EasyPDM #9)
