Gridfinity v1.4.1

Gridfinity bins (hollow, eco or solid), baseplates, and drawer baseplates split to fit your printer or a picked drawer floor, on a full, half or custom grid. Edit bin changes a bin it made, keeping each setting left at Keep.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Gridfinity bin
  • Gridfinity baseplate
  • Gridfinity drawer baseplate
  • Edit Gridfinity bin

Install Gridfinity

  1. Download the zip above (from release v1.4.1).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v1.4.1 (2026-11-20)

Needs SolidCraft 0.45 or newer. For SolidCraft 0.43 or 0.44, use 1.3.1.

Edit bin improvements (#12)

  • Width and Depth sit together at the top of the Edit bin form, right under Bin.
  • Label text style, size, height and font can be changed in Edit bin too, each starting at Keep. Set the style to Flush (inlaid) to get the sunk text as a separate body for multicolour printing. For the font, - goes back to SolidCraft's built-in one.

Scripts can still say width and depth to Edit bin; the form calls them cells_x and cells_y. Bins, baseplates and drawers come out exactly as before.

Install

Download gridfinity-1.4.1.zip below, then in SolidCraft: Plugins › Install plugin… and pick the zip.

Tested with SolidCraft 0.45.0 on Linux, through solidcraft-cli and in the desktop app.
