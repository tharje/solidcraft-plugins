Gridfinity v1.3.1

Gridfinity bins (hollow, eco or solid for custom cutouts), baseplates and drawer baseplates split to fit your printer, on a full, half or custom grid.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Gridfinity bin
  • Gridfinity baseplate
  • Gridfinity drawer baseplate

Install Gridfinity

  1. Download the zip above (from release v1.3.1).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v1.3.1 (2026-11-19)

Fixed

Drawer floor goes up to the walls. When you click a drawer's floor, the plate now stops at the nearest wall on each side, also when the walls are separate bodies from the floor. Before, it only used the floor's own size, so a floor that runs in under the walls gave a plate that was too big.

Everything else is built exactly as before.

Install

Download gridfinity-1.3.1.zip below, then in SolidCraft: Plugins › Install plugin… and pick the zip. From a script, add "replace": true to update an installed version.

Tested with SolidCraft 0.43.0 and 0.44.1. The drawer baseplate's form needs SolidCraft 0.44 or newer: 0.43 can't open it because of the Drawer floor field. Bins and baseplates work in 0.43 as before, and scripts can use all three there. On macOS, use SolidCraft 0.43 or newer (0.41 and 0.42 crash there when any plugin runs).
