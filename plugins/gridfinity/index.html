Install Gridfinity

  1. Download the zip above (from release v1.7.1).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

It is on the SolidCraft Workshop too: its Open in SolidCraft button installs it, after SolidCraft shows what it asks for.

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v1.7.1 (2026-11-27)

Needs SolidCraft 0.50.0 or newer. For SolidCraft 0.49.1, use 1.7.0.

A grid on stackable lids (#13, thanks to sapstar)

A Stackable lid now has a baseplate's grid on top: a pocket over each cell, so the bins you put on it stand in place, as on a baseplate. The pockets stop 0.6 mm below a baseplate's top, so the lid's edge keeps a 0.4 mm wall (a lid is 0.5 mm narrower than a baseplate). A 3×2 lid takes 67.9 cm³.

Fewer buttons in the ribbon (#18, thanks to vilts)

The panel's ten helper commands (panel-refresh, quick-bin-…, layout-…, settings-change) no longer fill the Plugins group: they sit behind one Panel helpers button. They are for the Gridfinity panel; use the panel's buttons instead. SolidCraft can't hide them yet (tangency-labs/solidcraft#22060).
