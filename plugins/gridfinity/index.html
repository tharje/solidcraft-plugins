Gridfinity v1.5.0

Gridfinity bins (hollow, eco or solid), baseplates, and drawer baseplates split to fit your printer or a picked drawer floor, on a full, half or custom grid. Edit bin changes a bin it made, keeping each setting left at Keep.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Gridfinity bin
  • Gridfinity baseplate
  • Gridfinity drawer baseplate
  • Edit Gridfinity bin

Install Gridfinity

  1. Download the zip above (from release v1.5.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v1.5.0 (2026-11-23)

Needs SolidCraft 0.46.2 or newer. For SolidCraft 0.45, use 1.4.1; for 0.43 or 0.44, 1.3.1.

Label tab: None, For sticker or Printed text (#16, thanks to and-ref)

Label tab is now a dropdown. For sticker gives a plain tab and shows only Label tab width. Printed text also shows the text fields.

Walls flush with the stacking lip (#16)

The stacking lip used to hang over the scoop and the back of the label tab. Now, with Stacking lip on:

  • a scoop makes the front wall 2.6 mm thick, flush with the lip
  • a tab For sticker does the same for the back wall

The side walls stay as they are, and so does the back wall behind printed text. With dividers, only the outer front and back walls change. A 1x2x4 bin with a scoop and a sticker tab takes 33.6 cm³, compared with 31.0 before.

Label tab in low bins (#14, thanks to and-ref)

The label tab gets the width you ask for in a bin of any height. In a low bin its 45° underside runs down to the floor and the tab stands on a block.

Only the fields in use

Scoop radius only shows with Scoop Custom. Label tab width only shows with a label tab, and the label text fields only with Printed text. Edit bin works the same way.

For scripts

inside_label_tab takes "None", "For sticker" or "Printed text", and inside_scoop takes "None", "Auto" or "Custom". SolidCraft now checks these against the form, so true/false and scoop numbers from older scripts are refused. Bins already in a design still rebuild the same way in Edit bin.
