TubeCraft v0.4.0

Turns sketch lines and arcs into bent, coped and mitred round tube, for roll cages and tube frames. Each run makes one tube in its own size and copes it to the tubes already in the design, flush or square to the wall as a tube laser cuts.

Install TubeCraft

  1. Download the zip above (from release v0.4.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.4.0 (2026-11-25)

First public release.

  • Fixed: a perpendicular cope on a tube bent back past its own coped end deleted the tube and kept the off-cut. The larger piece of the split is now kept.
  • Fixed: with the perpendicular cope, a tube that ends on an earlier tube and crosses it again further along was cut back to the far side of the crossing. It is now coped at the end and cut in two at the crossing, with a warning.
  • Fixed: a closed loop with a sharp corner at its seam was accepted.
  • Fixed: a tube named Cope ... or Miter ... was not found by later runs. Such names are now refused.
  • Fixed: the run could reach SolidCraft's 256-call limit part-way through. It now counts every call and stops with its own message before it changes anything.
  • Fixed: a pipe whose path is not sketch curves stopped the run. It is skipped with a warning.
  • Fixed: the name's 40 limit counted bytes, not characters.
  • Changed: tube.cut_length_in is the stock to cut, for flush copes and miters too. tube.centreline_in is the centreline as drawn.
  • Added: each perpendicular_copes entry says which end it is at (end_mm).
  • Changed: the helper sketches are hidden by one call at the end of the run, one host call less per perpendicular cope.
