Filament Swatch v0.3.0

Filament sample tiles: brand, material, colour and temperatures in text, and thin steps that show how see-through the filament is.

Download .zip Source on GitHub

What it adds to SolidCraft

  • Filament swatch

Install Filament Swatch

  1. Download the zip above (from release v0.3.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.3.0 (2026-11-18)

New

Its own icon and a short name in the ribbon (SolidCraft 0.44): the button now says Swatch, with a swatch icon, instead of a plug and "Filam... swatch". Older SolidCraft versions ignore both.

Swatches come out exactly as before.

Install

Download filament-swatch-0.3.0.zip below, then in SolidCraft: Plugins › Install plugin… and pick the zip.

Tested with SolidCraft 0.43.0 and 0.44.1 on Linux. On macOS, use SolidCraft 0.43 or newer (0.41 and 0.42 crash there when any plugin runs).
