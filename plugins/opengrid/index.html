SolidCraft Plugins › openGrid

openGrid v0.3.0

openGrid wall and desk boards on the 28 mm grid, Full or Lite, with screw holes and cut corners, as editable sketches and features.

Download .zip Source on GitHub

What it adds to SolidCraft

  • openGrid board

Install openGrid

  1. Download the zip above (from release v0.3.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.3.0 (2026-11-18)

New

Its own icon and a short name in the ribbon (SolidCraft 0.44): the button now says Board, with an openGrid board icon, instead of a plug and "open... board". Older SolidCraft versions ignore both.

Boards come out exactly as before.

Install

Download opengrid-0.3.0.zip below, then in SolidCraft: Plugins › Install plugin… and pick the zip.

Tested with SolidCraft 0.43.0 and 0.44.1 on Linux. On macOS, use SolidCraft 0.43 or newer (0.41 and 0.42 crash there when any plugin runs). Not printed yet: please report how snaps fit.
