Install Code Mode

  1. Download the zip above (from release v0.1.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.1.0 (2026-11-26)

First release. Requires SolidCraft 0.50.0 or later.

Added

  • Three MCP tools: codemode.run {code} runs a JavaScript script in the open design as one undo step, codemode.new {name?} starts a new, empty design, and codemode.design {} lists the bodies and parts.
  • The scx v15.1 vocabulary ported to JavaScript: box, cylinder, cone, sphere, hole, sketch (with rect, circle, slot, polygon, poly, extrude, revolve), loft, fillet, chamfer, hollow, shell, combine, move, remove, rename, color, part, measure, bodies, edges, faces, and cmd(id, params) for 128 SolidCraft commands. The reply lists what changed, in scx's format.
  • help(id) prints a command's parameters; help() lists the command ids a script can run.
  • The agent sees the vocabulary as TypeScript declarations, with three examples.
  • Error messages give the script line, and any error undoes the whole script.
  • codemode.run is a long job: a big script may run up to 10 minutes. It shows its progress as a row "Code Mode: Run" in the operations panel, where it can be cancelled.
  • A "Code Mode" button on the Model tab.
  • A benchmark against SolidCraft's classic MCP tools (bench/): on the 23 tasks of scx, with Claude Haiku 5.5, 72 % fewer tool calls and 78 % lower cost, with every run passing in both arms. Building a robot chassis from a photo with Claude Sonnet 5.5 (10 runs per arm): 55 % lower cost, 86 % fewer tool calls, parts of the same look.
  • The README tells how to make an agent use Code Mode (a paragraph for the prompt or CLAUDE.md).
