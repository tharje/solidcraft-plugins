What's new in v0.1.0 (2026-11-27)

Needs SolidCraft 0.50.0 or newer (tested on 0.50.0).

  • Eight gear entries, each building ordinary SolidCraft features grouped in the timeline: spur, helical, herringbone, internal (straight, helical or herringbone teeth), rack (straight or helical), bevel (straight), worm and worm-wheel.
  • Involute tooth profiles with the rack cutter's root trochoid (undercut reproduced and reported), profile shift, pressure angle, backlash, addendum, dedendum and root fillet; bore and JIS B 1301 keyway where it applies.
  • Placement by picking a position and an axis in the viewport (sketch points and lines, circular and straight edges, cylindrical and flat faces), a default axis and a flip; from scripts and agents also references to origin axes, planes, construction points and vertices, a bare world coordinate and a direction vector.
  • "Recommended values" for machining and for 3D printing, which set the clearances from the module (starting values).
  • center-distance, a calculator for external, internal, rack and worm pairs, with the working centre distance and pressure angle for shifted gears; results shown live in the dialog.
  • Usable from SolidCraft's MCP server and from solidcraft-cli scripts (plugin.run).
  • No permissions requested: no files, no network, no settings.
