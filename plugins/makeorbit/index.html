An MakeOrbit senden v0.2.0

Konstruktion als STEP/STL/3MF mit Quellstand an MakeOrbit übergeben (Archivierung dort mit Nachfrage) · Send STEP/STL/3MF with the design to MakeOrbit

Needs the MakeOrbit app, for now on macOS only (Windows is to follow).

Install An MakeOrbit senden

  1. Download the zip above (from release v0.2.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.2.0 (2026-11-16)

First public release.

  • makeorbit-cnc-studio-0.2.0.zip – “An MakeOrbit CNC Studio senden / Send to MakeOrbit CNC Studio”: exports the design as STEP; CNC Studio imports it after asking.
  • makeorbit-0.2.0.zip – “An MakeOrbit senden / Send to MakeOrbit”: STEP, STL (binary/ASCII), 3MF and the SolidCraft design; MakeOrbit asks which project to archive it in.

Requires SolidCraft 0.43.0 or newer, and on macOS MakeOrbit CNC Studio 0.5.16+ and/or MakeOrbit 2.9.18+. Install via Plugins › Install plugin… and grant the folder austausch (see README). Check the files against SHA256SUMS.txt.
