Code Maker v0.7.2

Puts a QR code, a barcode, an ArUco marker or an AprilTag on a plate or on a face of your model.

Download .zip Source on GitHub On the SolidCraft Workshop

Install Code Maker

  1. Download the zip above (from release v0.7.2).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

It is on the SolidCraft Workshop too: its Open in SolidCraft button installs it, after SolidCraft shows what it asks for.

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.7.2 (2026-11-27)

Changed

  • An inlay or an engraving is much faster, on a plate or on a face. The code is now made first, sunk into the part, and one combine cuts the part with it (an inlay keeps the code as its own body, an engraving uses it up). Cutting the outlines out of the part as an extrusion took several times longer, and the time grew so fast that a longer link hit the 30 s the host allows. The time now grows evenly with the length of the text, so an inlay or an engraving takes a link as long as a raised code does (200 outlines, about 150 characters). The plugin now asks the host for solid.combine.

| New plate, a link of | 0.7.1 | 0.7.2 | |---|---|---| | 56 characters (95 outlines), inlay | 16.0 s | 5.5 s | | 77 characters, inlay | 22.4 s | 7.7 s | | 97 characters, inlay | stopped at 30 s | 9.5 s | | 117 characters, inlay | stopped at 30 s | 10.3 s | | 56 characters, engraving | 13.3 s | 5.0 s |

Measured once each on a laptop, with the same link and the same size (40 mm) for both versions. On a face, a 120-outline inlay takes 8 s, where 0.7.1 stopped at 30 s.

Added

  • Pictures for the workshop: the three styles side by side, an inlay on a part and the types of code. The manifest lists them and takes the README as its description.
