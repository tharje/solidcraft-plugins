Code Maker v0.6.1

Puts a QR code, a barcode, an ArUco marker or an AprilTag on a plate or on a face of your model.

Download .zip Source on GitHub

Install Code Maker

  1. Download the zip above (from release v0.6.1).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.6.1 (2026-11-27)

Fixed

  • Fixed: the run failed with no face at [...] after the code was already drawn. The host refuses a whole colour call when one point of it falls off a face, which happens on thin faces once the point is rounded. The plugin now cuts a refused batch in halves until the faces it cannot find are alone, colours the rest, and says in the reply how many it left uncoloured instead of failing.

Added

  • A workshop manifest (solidcraft-workshop.json) and a screenshot (docs/screenshot.png) for SolidCraft's workshop.
