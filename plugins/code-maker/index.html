Code Maker v0.6.0

Puts a QR code, a barcode, an ArUco marker or an AprilTag on a plate or on a face of your model.

Install Code Maker

  1. Download the zip above (from release v0.6.0).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.6.0 (2026-11-26)

Added

  • ArUco markers and AprilTags: a Type of code list (QR code, ArUco marker, AprilTag), a Family list and a Marker number. The form offers the common families: ArUco 4x4, 5x5, 6x6 and original, and AprilTag 36h11, 16h5 and Standard 41h12. The plugin holds every official ArUco and AprilTag dictionary, taken from OpenCV and the AprilTag library, and every one was checked by decoding the drawn markers with OpenCV's ArUco detector and the AprilTag library (scripts/verify-tags.py).
  • Barcodes, written by the rxing library: Data Matrix, Aztec, PDF417, Code 128, Code 39, Code 93, Codabar, EAN-13, EAN-8, UPC-A, UPC-E and ITF, in the same Type of code list. A new Bar height field (barcodes only) sets how tall the bars are, and Size is the width of the whole barcode. Each was read back with the ZXing reader (scripts/verify-barcodes.py). The plugin grows from 0.2 MB to 1.6 MB.
  • Markers and barcodes go on a new plate or on a face, raised or engraved, coloured and moved like a QR code, and are named ArUco marker 2, EAN-13 2, and so on when the design has some already.
  • The reply says the kind of the code.
  • A new icon in the isometric style of SolidCraft's own: a plate with a flat raised marker, drawn with the paths, colours and round line ends SolidCraft's icon check requires.

Changed

  • The plugin is renamed Code Maker (id code-maker, button Code), since it is no longer only QR codes. The entry is now code-maker.code, which SolidCraft's MCP server exposes as code-maker_code (it was qr-code_qr). Remove the old QR Code plugin before installing this one.
