What's new in v1.4.0 (2026-11-24)

Zahnrad-Generator 1.4.0

English: Open-source (MIT) plugin for SolidCraft that generates involute gears and gear sets as ordinary, editable solids. Tested with SolidCraft 0.46.2. The user interface is German.

New in 1.4.0

  • Joints and motion simulation built in: every gear is built as its own component. The plugin adds revolute joints (a slider joint for the rack), the gear coupling with the correct ratio and a drive motion study, so you can simulate the motion right away. Can be switched off with the option "Drehgelenke + Kopplung einbauen" (build joints + coupling).
  • Crown gear with exact flank (envelope of the pinion's involute profile); face width 0 = automatic.
  • Body names include tooth count, module and ratio, e.g. "Ritzel Z15 m2" (pinion), "Rad Z45 m2 (i=3)" (wheel).
  • Gearbox: the ratio i accumulates per stage, i = Z2/Z1 · Z4/Z3 · … (pitch circles, not tip circles).

Included

Spur gear, internal gear, rack, worm and worm wheel, bevel gear, crown gear, matching gear pairs and multi-stage gearboxes.

Installation

Download zahnrad-1.4.0.zip, unpack it and put the folder into SolidCraft's plugin folder (Preferences → Plugins → *Show in folder*), then install and approve the plugin there. A plugin runs Wasm code, so review the source first.

Known limits

For the internal gear, the worm and the gearbox stage Z10/Z50 the collision check still reports 0.03–0.1 mm of contact that SolidCraft could not measure. The bevel gear is a geometric approximation. At most about 64 host calls per run (gearbox: field "Ab Stufe" to continue).
