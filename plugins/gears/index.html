Install Зубчатые передачи

  1. Download the zip above (from release v0.10.10).
  2. In SolidCraft: Plugins › Install plugin… and pick the zip.
  3. Run it from the Plugins menu, or its button in the ribbon (SolidCraft 0.42 and later).

Questions and bug reports go to the plugin's author, in the issues on GitHub. If it crashes SolidCraft, harms a design or looks unsafe, please also report it to this list, so others can be warned.

What's new in v0.10.10 (2026-11-28)

Зубчатые передачи 0.10.10

В SolidCraft 0.51.2 проверены предпросмотр всех 13 команд и 27 построений с исходными и изменёнными параметрами. В каждом построении получено ожидаемое число замкнутых тел с положительным объёмом.

| Команда | Тел при исходных настройках | Дополнительная проверка | | --- | ---: | --- | | Прямозубое колесо | 1 | Задание по двум роликам, бочкообразность зубьев | | Косозубое колесо | 1 | Задание по делительному диаметру, левый зуб, плоскость YZ | | Шевронное колесо | 1 | Отверстие, плоскость XZ, левое направление первой половины | | Колесо с внутренними зубьями | 1 | Пересчёт зацепления с указанной шестернёй | | Коническое колесо | 1 | Пример 15/30 зубьев из приложения 4 ГОСТ 19624-74 | | Гипоидная передача | 1 | Поочерёдное построение колеса и шестерни | | Червяк | 1 | Многовитковое тело, левый двухзаходный червяк со сквозным отверстием | | Червячное колесо | 1 | Двухзаходный левый червяк в исходных данных | | Зубчатая рейка | 2 | Построение отдельно и с шестернёй | | Планетарная передача | 5 | Два сочетания чисел зубьев и модуля | | Циклоидальные колёса | 2 | Построение отдельно и в паре | | Циклоидальный редуктор | 2 | Диск без выходных отверстий и с одним отверстием | | Зубчатая пара | 2 | Нечётные числа зубьев, разные отверстия |

В формах доступно 139 расчётных полей. Набор видимых величин зависит от команды и способа задания. Для рейки и гипоидной пары вынесены размеры сопряжённых деталей. Для редуктора с выходными пальцами выводятся диаметр и окружность размещения отверстий. Размеры в форме и при построении рассчитываются из одних исходных данных.
